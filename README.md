# FrontendDevReactjs-Nadhif-Al-Rozin

This is a frontend development project using React.js, created by Nadhif Al Rozin. The project is built with Vite and Node.js, and it serves as a demonstration of my skills in frontend development.

## Tech Stack

- React 18.2.0
- Vite 5.1.0
- Node.js v20.11.1

## Requirements

- Node.js v20.11.1 or newer
- npm or yarn

## How to Start

Using npm:

```bash
npm install
npm run dev
```

If you want to run the API server separately (not using MOCK):

```bash
npm run server
```

create .env file and set VITE_USE_MOCK_API=false (if not using MOCK)
